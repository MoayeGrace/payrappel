## Project

PayRappel — a Flutter app for managing clients, invoices, partial payments, and automatic payment reminders. Targets **Android and iOS only**. Built phase by phase with a non-developer owner; keep explanations clear and changes incremental.

## Architecture

Three-layer architecture under `lib/`:

```
core/          → Shared constants and utilities (no Flutter/Firebase deps)
data/          → Firebase layer: models, repositories, services
domain/        → Business logic (balance calculation, invoice status)
presentation/  → Screens and widgets, one folder per feature
```

**Data flow:** `presentation` calls `repositories` (in `data/`) which talk to Firebase. Business rules (e.g., computing remaining balance) live in `domain/`, called by repositories or screens.

**State management:** `provider` package. Each feature screen has its own provider/ChangeNotifier when needed.

**Navigation:** `go_router`. All routes are declared in `lib/app.dart`. The router's `redirect` guards unauthenticated access — anonymous users are considered authenticated and pass through.

## Key patterns

**Guest mode:** Users can skip login. `AuthRepository.signInAnonymously()` creates an invisible Firebase anonymous account. When the guest later registers, `linkGuestToEmail()` links their anonymous UID to an email — all their Firestore data is preserved because the UID stays the same.

**Offline support:** Firestore persistence is enabled in `FirebaseService.initialize()` with `cacheSizeBytes: CACHE_SIZE_UNLIMITED`. All Firestore reads work from local cache when offline.

**Repository pattern:** Each Firestore collection has its own repository class in `lib/data/repositories/`. Screens never call `FirebaseFirestore` directly.

**Firestore collections:** `users`, `clients`, `invoices`, `payments`, `reminders` — all scoped under the authenticated user's UID.

## Business rules

- `invoice.balance = invoice.totalAmount - sum(payments)`
- Invoice statuses: `draft`, `partial`, `paid`, `late`
- A reminder can be scheduled: before due date, on due date, or after overdue
- Free tier: max 20 clients, 30 operations/month, push notifications only
- Pro tier: unlimited, PDF/Excel export, WhatsApp reminders

## Firebase

- Auth: email/password + anonymous (guest mode)
- Firestore: offline persistence enabled, unlimited cache
- FCM: push notifications for payment reminders
- `lib/firebase_options.dart` is auto-generated by FlutterFire CLI — do not edit manually

## Currency and locale

All monetary amounts are in **FCFA** (West African CFA franc). Use `CurrencyFormatter.format()` for display. Use `DateFormatter` for all date display — French locale (`fr_FR`).
